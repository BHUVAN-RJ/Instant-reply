# Design mockups

Every theme's mockups live here, one folder per theme, named on the `Mockup:` line of its DESIGN.md.
Open them in a browser straight from disk.

- `kit/`: the mockup kit. Copy `kit/starter.html` to `<id>/mockup.html` to start a new theme; see
  `docs/THEMES.md` ("Mockups") for how it works.
- `fragpunk/mockup.html`: snapshot of the shipped FragPunk look (`npm run mockup:snapshot -- fragpunk`).
- `beach-style-v2.html`: the final beach look in all four time of day palettes, with the wave and the
  "New" carrier running on the Beach v1 numbers.
- `wave-tuning-lab.html`: the wave, sand and beach finds with every number on a slider. Choose
  "Beach v1 (picked)" under Saved look to load the final numbers.

The decisions themselves live in each theme's DESIGN.md.
