# Beach style reference

Mockups for the beach style (design v2, final). Open them in a browser; they are self contained.

- `beach-style-v2.html`: the final look (reply card, lagoon To line with the foam edge, sea glass Send, flower banner Refactor, plumeria switch, petal icons, flower crown avatar) in all four time of day palettes, with the wave and the "New" carrier running on the Beach v1 numbers.
- `wave-tuning-lab.html`: the wave, sand and beach finds with every number on a slider. Choose "Beach v1 (picked)" under Saved look to load the final numbers.

The decisions themselves live in `docs/PLAN.md` under "Look and feel".
